**Embedded Firmware | Bionic Robotics | Edge AI**

Electronics & Telecommunications undergraduate at UTT. I design low-level firmware in Modern C++ and build physical systems, focusing on bionic flight mechanisms, bipedal locomotion with Sim-to-Real RL, and TinyML on ESP32 and Raspberry Pi.

*Building from hardware to kinematics.*

* **Languages:** Modern C++ (C++17) • Python • C
